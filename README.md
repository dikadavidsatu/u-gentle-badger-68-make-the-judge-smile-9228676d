# Make the Judge Smile

Entry for make.fun competition
`u-gentle-badger-68-make-the-judge-smile-9228676d` — one line, at most 200
characters, about a small good thing that happened today.

## Run

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (or to `$ENTRY_OUTPUT`
when set, for local checks).

## The line

> This morning my neighbour left a mango on my doorstep with a note: 'from the tree you watered while I was away' — and I have never felt so quietly rich.

Why this line: it is a small good thing that happened today, it is warm
(a kindness quietly repaid), it turns where you do not expect (the note
reveals the narrator's own forgotten kindness), it carries concrete details
(the mango, the doorstep, the note, the tree), and it is told in its own
words rather than greeting-card phrasing.
